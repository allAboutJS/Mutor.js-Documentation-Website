Namespaces

Mutor templates execute inside an isolated environment. Unlike regular JavaScript, templates do not have access to global objects, runtime APIs, imported modules, or the surrounding execution scope.

To make common functionality available while preserving isolation, Mutor exposes a collection of built-in namespaces. These namespaces provide a carefully selected subset of functionality from JavaScript's standard library while maintaining strict boundaries around template execution.

Namespaces are accessed using the namespace operator and are available in every template by default.

Why Namespaces Exist

Templates are designed for presentation, not unrestricted code execution. Mutor therefore avoids exposing JavaScript globals directly and instead provides a controlled execution model through namespaces.

This allows templates to perform common operations such as date formatting, JSON serialization, object inspection, and mathematical calculations without exposing the runtime environment. 

\{{ Date::now() }}

\{{ Array::isArray(users) }}

\{{ JSON::stringify(user) }}

\{{ Math::floor(price) }}

Context Resolution

Unlike many template engines, Mutor does not require a context prefix. Properties provided to the renderer can be referenced directly from within templates. 

const data = {
  user: {
    name: "Victor"
  }
};

The property can then be accessed directly.

\{{ user.name }}

Internally, Mutor resolves identifiers against the provided context. Conceptually, the expression behaves as though it were accessing the context object directly. 

ctx.user.name

As a result, template expressions cannot escape their context and access arbitrary runtime objects. 

\{{ process.exit() }}

is interpreted as:

ctx.process.exit()

Namespace Syntax

Namespaces are referenced using the namespace operator. 

Namespace::member

A member may be either a property or a method exposed by the namespace. 

\{{ Date::now() }}

\{{ Math::PI }}

\{{ JSON::stringify(user) }}

The Mutor Namespace

The Mutor namespace provides functionality specific to the template engine itself.

Member Description
include(path, context?) Includes and renders another template.
await(promise) Resolves a Promise in async templates.
iter.index Current loop index inside a for...of loop. 
\{{ Mutor::include("components/card") }}

\{{ Mutor::await(fetchUser()) }}

\{{ Mutor::iter.index }}

Built-in Namespaces

JSON

Provides JSON serialization and parsing utilities.

Method Description
stringify(value, space?) Converts a value into a JSON string.
parse(string) Parses a JSON string.

Object

Provides utilities for inspecting and transforming objects.

Method Description
keys(obj) Returns object keys.
values(obj) Returns object values.
entries(obj) Returns object entries.
hasOwn(obj, key) Checks whether a property exists directly on an object.
fromEntries(entries) Creates an object from entries.
pick(obj, keys) Creates a new object containing only selected keys.
omit(obj, keys) Creates a new object excluding selected keys.

Array

Provides array inspection, transformation, and generation utilities.

Method Description
isArray(value) Checks if a value is an array.
from(value) Creates an array from an iterable.
of(...values) Creates an array from values.
unique(array) Removes duplicate values.
compact(array) Removes falsy values.
chunk(array, size) Splits an array into chunks.
range(start, end, step?) Generates a numeric range.

Number

Method Description
isFinite(value) Checks finiteness.
isNaN(value) Checks NaN.
isInteger(value) Checks integer values.
parseInt(value, radix?) Parses an integer.
parseFloat(value) Parses a floating-point number.
clamp(value, min, max) Constrains a value to a range.
toFixed(value, digits?) Formats a number with fixed decimals.
random(min?, max?) Generates a random number.

String

Method Description
fromCharCode(...codes) Creates a string from character codes.
capitalize(value) Capitalizes the first character.

Math

Member Description
PI Pi constant.
abs(x) Absolute value.
floor(x) Rounds down.
ceil(x) Rounds up.
round(x) Rounds normally.
trunc(x) Removes decimals.
sign(x) Returns sign.
sqrt(x) Square root.
pow(base, exponent) Exponentiation.
max(...values) Largest value.
min(...values) Smallest value.
random() Random number.

Date

Method Description
now() Current timestamp.
parse(value) Parses a date string.
new(value?) Creates a Date instance.
iso(value?) Returns an ISO string.
timestamp(value?) Returns a timestamp.

Boolean

Method Description
valueOf(value) Converts a value to a boolean.

URL

Method Description
encode(value) Encodes a URI component.
decode(value) Decodes a URI component.

Security Considerations

Mutor resolves identifiers exclusively against the template context and registered namespaces. Objects outside those boundaries are not accessible from template expressions.

The integrity of the rendering context remains the responsibility of the application. Any object intentionally exposed through the context remains available to template code.
