Quick Start

Execute common compilation workflows across different environment paradigms. These baseline execution sheets establish syntax benchmarks for single-pass renders, optimized functional iterations, and server-side I/O processing.

Basic Render

Performs immediate compilation and synchronous variable assignment on raw string inputs. Best suited for single-pass evaluations where cache persistence is handled outside the execution loop. 

import Mutor from "mutorjs";

const mutor = new Mutor();

const output = mutor.render(
  `<h1>\{{ greeting }}, \{{ user.name }}!</h1>`,
  { greeting: "Hello", user: { name: "Onah" } }
);

console.log(output);
// <h1>Hello, Onah!</h1>

Compile Once, Execute Many Times

Compiles template strings directly into an abstract syntax tree and generates a native JavaScript runner function. This completely eliminates internal parsing and string analysis overhead during multi-item loops. 

import Mutor from "mutorjs";

const mutor = new Mutor();

const fn = mutor.compile(`<p>\{{ item.title }}</p>`);

const items = [
  { title: "Alpha" },
  { title: "Beta" },
  { title: "Gamma" }
];

// Reuses the optimized native function references directly
const rendered = items.map(item => fn({ item }));

File Rendering (Server Only)

Performs non-blocking disk operations using the isolated server module bundle. Resolves absolute local project file targets, handles internal storage streaming, and updates hot-reload cache buffers. 

import Mutor from "mutorjs/server";

const mutor = new Mutor();

// Direct async asynchronous operating system layout call

Component Rendering

Registers fragments into global instance memory to let components stitch and reuse layout sub-sections dynamically across client-side runtimes or asset bundlers. 

<!-- ES Module isolated runtime import -->
import Mutor from "mutorjs";

const mutor = new Mutor();

mutor.registerComponent(
  "card",
  `  <div class="card">
    <h2>\{{ card.title }}</h2>
    <p>\{{ card.body }}</p>
  </div>`
);

// Direct modular block lookup and resolution execution pass
const output = mutor.renderComponent("card", {
  card: { title: "Notice", body: "This is a component." }
});
