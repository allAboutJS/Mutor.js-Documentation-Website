Data Traversal

High-performance loops.

01. Collections

The for...of Loop

Designed for iterating over iterable collections, primarily arrays. It maps directly down to native loops inside the compiled JavaScript execution function. 

<!-- Iterating through item list collections -->
<ul>
\{{ for item of items }}
  <li>\{{ item.name }}</li>
\{{ end }}
</ul>
02. Keys

The for...in Loop

Tailored for enumerating over keys or dictionary property keys of an object map while maintaining property-access security. 

<!-- Extracting object dictionary key strings -->
<dl>
\{{ for key in record }}
  <dt>\{{ key }}</dt>
\{{ end }}
</dl>
