Up in minutes.

npm install mutorjs

01

Standard Rendering

Simple, direct templating for lightweight views.

import Mutor from "mutorjs";

const engine = new Mutor();

const output = engine.render(
  `<h1>\{{ title }}</h1>`,
  { title: "Mutor.js" }
);
02

Compiled Execution

Cache the compiled function for maximum throughput.

const engine = new Mutor();
const fn = engine.compile(
  `<div>\{{ data }}</div>`
);

// Zero re-parsing on every call
const results = list.map(
  item => fn({ data: item })
);
