The Namespace System

Mutor.js restricts raw global scope access. Instead, it exposes a custom :: operator to securely route lookups to safe, audited built-in utility pathways.

Safe Utility Execution

Direct expression parsing keeps template lookups clean and predictable.

<!-- Math namespace routing -->
<p>Price: \{{ Math::floor(product.price) }} USD</p>

<!-- Dynamic data inspection -->
<pre>\{{ JSON::stringify(debug.payload) }}</pre>

<!-- Array verification checks -->
<p>Valid: \{{ Array::isArray(items) ? "yes" : "no" }}</p>
