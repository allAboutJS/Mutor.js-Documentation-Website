Memory-Aware Caching

Mutor.js allows explicit cache sizing. By configuring maxSize, you prevent memory exhaustion in high-traffic environments while maintaining near-native execution speeds for hot components. 

const engine = new Mutor({
  cache: { maxSize: 1024 * 1024 * 50 /* 50mb */ }
});

Execution Environments

Separate runtime targets for browser components and server rendering.


// Register the component (compile and cache)
engine.registerComponent("name", templateString);
// No more compilation (direct execution)
engine.renderComponent("name", { key: 'home-page' });

// Server
// Cache misses, first call compiles and caches
engine.renderFile(templateString, { key: 'home-page' });
// Subsequent server renders (hit cache)
engine.renderFile(templateString, { key: 'home-page' });
