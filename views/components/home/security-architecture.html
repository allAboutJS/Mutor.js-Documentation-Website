Security

Hardened by Design.

Sandbox Enforcement

Mutor.js enforces a strict security model at compile time. By utilizing allowedProps and forbiddenProps, we ensure the sandbox cannot leak into the global scope.

Compile-time Validation No Global Access
// MutorConfig Security Enforcement 
const mutor = new Mutor({
  allowedProps: new Set(['prototype', 'getOwnPropertyDescriptor']),
  forbiddenProps: new Set(['constructor', 'getPrototypeOf'])
});
