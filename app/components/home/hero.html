Sync-only runtime · Safe by default

A template engine built for predictable production rendering

Mutor.js gives you fast synchronous rendering, first-class layouts, includes, file rendering, and sensible security defaults without turning templates into unrestricted JavaScript.

Default safety

Escaped output, blocked dangerous properties, and function calls disabled by default.

Composable

Use includes, registered components, layouts, server rendering, and directory builds.

Practical syntax

Conditionals, loops, namespaces, whitespace control, and context-aware rendering.
